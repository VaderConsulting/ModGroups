# ModGroups

VB6 Modify Group membership utility (`ModGroups.exe`) that lists filtered domain groups (e.g. `right-usr-pf*` / `right-usr-gf*`) via ADSI and shows a user or computer's current group memberships for review/modification. Open `ModGroups.vbp` in the VB6 IDE.
